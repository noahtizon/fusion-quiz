# FUSION Personality Quiz

A BuzzFeed-style personality quiz to help FUSION members discover their archetype and find their perfect programs!

## 🎯 Features

- **5 Unique Archetypes**: Builder, Networker, Academic Weapon, Social Butterfly, and Connector
- **Interactive Design**: Smooth animations and engaging UI inspired by the FUSION logo
- **Mobile Responsive**: Looks great on all devices
- **Share Results**: Easy sharing functionality for social media
- **Program Recommendations**: Each result includes recommended FUSION programs

## 🎨 Visual Design

The quiz features a modern design inspired by the FUSION logo with:
- **Color Scheme**: Gray and yellow/gold color palette matching the gear/sun logo
- **Animated Logo**: Rotating gear with sun elements
- **Smooth Transitions**: Engaging animations throughout the user journey
- **Clean Layout**: BuzzFeed-style question cards and result displays

## 🚀 How to Use

1. Open `index.html` in any modern web browser
2. Click "Start Quiz" to begin
3. Answer all 7 questions honestly
4. View your personalized archetype result
5. Check out your recommended FUSION programs
6. Share your result with friends!

## 📱 Browser Compatibility

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## 🔧 Technical Details

- **HTML5**: Semantic structure with accessibility in mind
- **CSS3**: Modern features including CSS Grid, Flexbox, and custom properties
- **Vanilla JavaScript**: No dependencies, lightweight and fast
- **Progressive Enhancement**: Works even with JavaScript disabled (basic functionality)
